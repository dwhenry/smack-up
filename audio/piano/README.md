# Piano sounds

The moo, baa and notes are made by the game itself. The fart is a real recording, sped up or slowed down by the game to play each note.

| File | What | Where it's from | Licence |
|---|---|---|---|
| `fart.mp3` | One long fart, about 1.5 seconds | [“Flatulence #1”, BigSoundBank](https://bigsoundbank.com/pet-1-s0111.html) | CC0 (public domain): free to use for anything, no credit needed |

To swap it for a different fart, replace `fart.mp3` with another short recording that holds roughly one pitch. Then set `FART_HZ` in [piano/index.html](../../piano/index.html) to that pitch, so the keys stay in tune with each other.
