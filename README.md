# Gaze Games

Games for children learning to use an eye-gaze device. Every game follows the mouse pointer, so it works with any eye tracker that can move the pointer, such as a Tobii Dynavox I-12+ in its mouse or computer-control mode. Looking at something long enough counts as choosing it.

Play at **https://smack-up.decoybecoy.com**

| Game | What it is |
|---|---|
| [Smack Up](smack-up/) | Family photos float down on parachutes. Stare at one and it gets splatted with a pie, a cake, an egg or a rubber chicken. [Set-up guide](smack-up/README.md) |

Each game is a single `index.html` in its own folder, with nothing to build. The site is hosted on GitHub Pages from the `main` branch.
